An attractive, well-documented summary of the IPL data-science tasks and analyses included in this repository.

Highlights
- Clean exploratory analysis of IPL match data
- Visualizations for team performance, toss impact, and venues
- Reproducible environment with `requirements.txt`

Quick start
1. Clone the repo

```bash
git clone https://github.com/nikhilmanvi360/data-science-internship-task.git
cd data-science-internship-task
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

2. Run the analysis

```bash
python ipl_analysis.py
```

Files of interest
- `ipl_analysis.py` — main analysis script
- `ipl_matches_100.csv` — sample dataset included
- `projectoverview.md` — project overview and aims
