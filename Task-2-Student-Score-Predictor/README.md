# Task 2: Student Score Predictor

A Linear Regression model designed to predict student exam scores based on study hours. This tool proactively identifies at-risk students by forecasting results.

## 📁 Structure

- `student_score_predictor.py` — Main ML script
- `outputs/` — Generated EDA and regression plots

## 🚀 How to Run

Ensure you are in this directory and your virtual environment is activated:

```bash
python3 student_score_predictor.py
```

## 📈 Model Performance

- **R² Score**: ~0.93
- The model shows a strong linear correlation between study hours and exam marks.
