# Task 1: IPL Cricket Data Analytics

This project highlights team performance, toss impact, and venue statistics using historical IPL match data.

## 📁 Structure

- `ipl_analysis.py` — Main analysis script
- `data/` — Contains the IPL matches dataset
- `outputs/` — Generated plots and visualizations
- `docs/` — Detailed documentation and guides

## 🚀 How to Run

Ensure you are in this directory and your virtual environment is activated:

```bash
python3 ipl_analysis.py
```

## 📊 Key Findings

- Toss winners have a surprisingly low win rate (~17%).
- Team strength and strategy are more decisive than the coin toss.
